## Operators

Operators are like verbs in programming. They perform operations on variables and values. C has a rich set of operators, which can be categorized as follows:
- Arithmetic Operators: Used for basic mathematical operations like addition, subtraction, multiplication, and division.
- Unary Operators: Operate on a single operand to produce a new value, such as incrementing or negating a value.
- Increment and Decrement Operators: Used to increase or decrease the value of a variable by one.
- Relational Operators: Compare two values and return a boolean result (true or false).
- Cast Operator: Used to convert a variable from one type to another.

### Arithmetic Assignment Operators

The `=` is called _assignment operator_ and is used to assign the value of the right-hand operand to the left-hand operand.

The general form of an assignment statement is:

```c
left-hand-operand = right-hand-operand;
```

The value of the `right-hand-operand` is assigned (or written) to the memory location of the `left-hand-operand`. After the assignment, the value of the `left-hand-operand` is the same as the value of the `right-hand-operand`.

`a = 5;` writes the value of the `right-hand-operand` (`5`) into the memory location of the `int` variable `a`. After the assignment, the value of `a` is `5`.

`b = a = 5;` is equivalent to `a = 5; b = a;`. The value of the `right-hand-operand` (`5`) is assigned to the memory location of the `int` variable `a`, and then the value of `a` (`5`) is assigned to the memory location of the `int` variable `b`. After the assignment, both `a` and `b` have the value of `5`.

The value on the left must be some form of variable that can receive data from the expression on the right. `6 = a;` is invalid because `6` is a constant and cannot receive data. The left-hand side of an assignment must be a variable, not a constant.

#### Combine Arithmetics Operators with `=`

Lets take a look at the following example: Given two integers `x` and `y`, how do you assign the addition of `x` and `y` back to `x`? You can do it like this:

```c
x = x + y;
```

But C provides a shorthand for this operation, which is:

```c
x += y; // This is equivalent to x = x + y;
```

This is works for all arithmetic operators:

| **Operator** | **Shorthand** | **Equivalent Expression** |
|--------------|---------------|---------------------------|
| `+=` | `x += y` | `x = x + y` |
| `-=` | `x -= y` | `x = x - y` |
| `*=` | `x *= y` | `x = x * y` |
| `/=` | `x /= y` | `x = x / y` |
| `%=` | `x %= y` | `x = x % y` |

:::warning
```c
z = z * x + y;
```

is not equivalent to:

```c
z *= x + y;
```

it is equivalent to:

```c
z = z * (x + y);
```
:::

### Unary Minus Operator

We can use the unary `-` operator, right before the number, to change the sign of a number. This operator can be on any integer or floating-point number. For example, `-5` is the negative of `5`, and `-3.14` is the negative of `3.14`. The unary minus operator can also be used to negate a variable, such as `-x`, which negates the value of `x`.

### Increment and Decrement Operators

Very handy to add or subtract `1` from a variable are the increment (`++`) and decrement (`--`) operators. Instead of writing `x = x + 1;` or `x = x - 1;`, you can use these operators `++x` or `--x`. These operators can be used in two forms: prefix and postfix.

- **Prefix**: The operator is placed before the variable. For example, `++x` increments the value of `x` by `1` and returns the new value of `x`. Similarly, `--x` decrements the value of `x` by `1` and returns the new value of `x`.

- **Postfix**: The operator is placed after the variable. For example, `x++` increments the value of `x` by `1` but returns the old value of `x`. Similarly, `x--` decrements the value of `x` by `1` but returns the old value of `x`. For example `y = x++;` assigns the old value of `x` to `y`, and then increments `x` by `1`.

```c
#include <stdio.h>

main()
{
    int w, x, y, z, result;

    w = x = y = z = 1;

    result = ++w;
    printf("++w evaluates to %d and w is now %d\n", result, w);
    result = x++;
    printf("x++ evaluates to %d and x is now %d\n", result, x);
    result = --y;
    printf("--y evaluates to %d and y is now %d\n", result, y);
    result = z--;
    printf("z-- evaluates to %d and z is now %d\n", result, z);
    return 0;
}
```

Output:

```
++w evaluates to 2 and w is now 2
x++ evaluates to 1 and x is now 2
--y evaluates to 0 and y is now 0
z-- evaluates to 1 and z is now 0
```

### Relational Operators

Relational operators are used to compare two values. They return `1` (true) if the comparison is true, and `0` (false) if the comparison is false. The relational operators in C are:

| **Operator** | **Description** |
|--------------|----------------|
| `==` | Equal to |
| `!=` | Not equal to |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |

Their precedence is lower than that of arithmetic operators, but higher than that of logical operators. For example, `x + y > z` is evaluated as `(x + y) > z`, not `x + (y > z)`.

Among the relational operators, the `>, <, >=, <=` operators have higher precedence than the `==` and `!=` operators. For example, `x == y > z` is evaluated as `x == (y > z)`, not `(x == y) > z`.

Relational expressions evaluate to `1` (true) or `0` (false). For example, the expression `x > y` evaluates to `1` if `x` is greater than `y`, and `0` otherwise. Similarly, the expression `x == y` evaluates to `1` if `x` is equal to `y`, and `0` otherwise.

### Cast Operator

We can convert the data type of a variable, expression or constant to another data type using the cast operator. The cast operator is a unary operator that is placed before the variable, expression or constant to be converted. The conversion does not change the operand itself, but rather creates a new value of the specified type

The syntax for the cast operator is:

```c
(type) expression
```

Where `type` is the data type to which we want to convert the expression, and `expression` is the value or variable to be converted. For example, `(float) x` converts the integer variable `x` to a floating-point value.

```c
#include <stdio.h>

main()
{
    int x, y;

    x = 7;
    y = 5;

    printf("x / y = %d\n", x / y);
    printf("(float) x / y = %f\n", (float) x / y);
    return 0;
}
```

Output:

```
x / y = 1
(float) x / y = 1.400000
```

### Logical Operators

There are three logical operators in C:

| **Operator** | **Description** |
|--------------|----------------|
| `&&` | Logical AND |
| `||` | Logical OR |
| `!` | Logical NOT |

#### Logical AND Operator

The logical AND operator (`&&`) returns `1` (true) if both operands are true, and `0` (false) otherwise.

A general form of the logical AND operator is:

```c
expression1 && expression2
```

The truth table for the logical AND operator is:

| **expression1** | **expression2** | **result** |
|-----------------|-----------------|------------|
| 0 | 0 | 0 |
| 0 | `nonzero` | 0 |
| `nonzero` | 0 | 0 |
| `nonzero` | `nonzero` | 1 |

Example:

```c
#include <stdio.h>

main()
{
    int x, y;

    x = 5;
    y = 10;

    if (x > 0 && y > 0) {
        printf("Both x and y are positive numbers.\n");
    } else {
        printf("At least one of x or y is not a positive number.\n");
    }
    return 0;
}
```

#### Logical OR Operator

The logical OR operator (`||`) returns `1` (true) if at least one of the operands is true, and `0` (false) if both operands are false.

A general form of the logical OR operator is:

```c
expression1 || expression2
```

The truth table for the logical OR operator is:

| **expression1** | **expression2** | **result** |
|-----------------|-----------------|------------|
| 0 | 0 | 0 |
| 0 | `nonzero` | 1 |
| `nonzero` | 0 | 1 |
| `nonzero` | `nonzero` | 1 |

Example:

```c
#include <stdio.h>

main()
{
    int x, y;

    x = -5;
    y = 10;

    if (x > 0 || y > 0) {
        printf("At least one of x or y is a positive number.\n");
    } else {
        printf("Both x and y are not positive numbers.\n");
    }
    return 0;
}
```

#### Logical NOT Operator

The logical NOT operator (`!`) returns `1` (true) if the operand is false, and `0` (false) if the operand is true.

A general form of the logical NOT operator is:

```c
!expression
```

The truth table for the logical NOT operator is:

| **expression** | **result** |
|----------------|------------|
| 0              | 1          |
| `nonzero`      | 0          |

Example:

```c
#include <stdio.h>

main()
{
    int num;

    num = 5;

    printf("Given num = %d\n", num);
    printf("!(num < 5) = %d\n", !(num < 5));
    printf("!(num > 5) = %d\n", !(num > 5));
    printf("!(num == 5) = %d\n", !(num == 5));

    return 0;
}
```

Output:

```
Given num = 5
!(num < 5) = 1
!(num > 5) = 1
!(num == 5) = 0
```

### Binary Operators

Before we start to manipulate bits, we will learn more about binary and hex numbers.

#### Converting Decimal to Hex or Binary

A bit is the smallest unit of data in a computer, and it can have a value of either `0` or `1`. Hex number consists of 4 bits.

Here is a table that shows the decimal, binary, and hexadecimal representations of the numbers from `0` to `15`:

| **Hex** | **Binary** | **Decimal** |
|---------|------------|-------------|
| 0       | 0000       | 0           |
| 1       | 0001       | 1           |
| 2       | 0010       | 2           |
| 3       | 0011       | 3           |
| 4       | 0100       | 4           |
| 5       | 0101       | 5           |
| 6       | 0110       | 6           |
| 7       | 0111       | 7           |
| 8       | 1000       | 8           |
| 9       | 1001       | 9           |
| A       | 1010       | 10          |
| B       | 1011       | 11          |
| C       | 1100       | 12          |
| D       | 1101       | 13          |
| E       | 1110       | 14          |
| F       | 1111       | 15          |

Calculation of the decimal value of a binary number is done by multiplying each bit by `2` raised to the power of its position, starting from `0` on the right. For example, the binary number `1011` can be calculated as follows:

$$
1 * 2^3 + 0 * 2^2 + 1 * 2^1 + 1 * 2^0 = 2^3 + 0 * 2^2 + 2^1 + 2^0 = 8 + 0 + 2 + 1 = 11
$$

The other way around, to convert a decimal number to binary, we can use the following steps:
1. Divide the decimal number by `2`.
2. Write down the remainder (this will be the least significant bit).
3. Divide the quotient obtained in step 1 by `2` again.
4. Repeat steps 2 and 3 until the quotient is `0`.

Example: Convert the decimal number `13` to binary:
1. 13 / 2 = 6 remainder 1 (LSB)
2. 6 / 2 = 3 remainder 0
3. 3 / 2 = 1 remainder 1
4. 1 / 2 = 0 remainder 1 (MSB)

Therefore, `13` in decimal is `1101` in binary.

In order to convert a decimal number to hexadecimal, we can use the following steps:
1. Divide the decimal number by `16`.
2. Write down the remainder (this will be the least significant digit).
3. Divide the quotient obtained in step 1 by `16` again.
4. Repeat steps 2 and 3 until the quotient is `0`.

Example: Convert the decimal number `251` to hexadecimal:
1. 251 / 16 = 15 remainder 11 (B in hex)
2. 15 / 16 = 0 remainder 15 (F in hex)

Therefore, `251` in decimal is `FB` in hexadecimal.

The other way around, to convert a hexadecimal number to decimal, we can use the following steps:
1. Write down the hexadecimal number.
2. Multiply each digit by `16` raised to the power of its position, starting from `0` on the right.
3. Add up all the results.

Example: Convert the hexadecimal number `FA3` to decimal:
1. F * 16^2 + A * 16^1 + 3 * 16^0
2. 15 * 256 + 10 * 16 + 3 * 1
3. 3840 + 160 + 3 = 4003

#### Bitwise Operators

There are six bitwise operators in C:

| **Operator** | **Description** |
|--------------|----------------|
| `&` | Bitwise AND |
| `|` | Bitwise OR |
| `^` | Bitwise XOR (exclusive OR) |
| `~` | Bitwise NOT (complement) |
| `<<` | Left shift |
| `>>` | Right shift |

##### Bitwise AND Operator

The bitwise AND operator `&` performs a logical AND operation on each pair of corresponding bits of its operands. The result is `1` if both bits are `1`, otherwise it is `0`.

General form of the bitwise AND operator is:

```c
expression1 & expression2
```

Example:
```c
int a = 5;  // 0101 in binary
int b = 3;  // 0011 in binary
int c = a & b;  // 0001 in binary, which is 1 in decimal
```

##### Bitwise OR Operator

The bitwise OR operator `|` performs a logical OR operation on each pair of corresponding bits of its operands. The result is `1` if at least one of the bits is `1`, otherwise it is `0`.

General form of the bitwise OR operator is:

```c
expression1 | expression2
```

Example:
```c
int a = 5;  // 0101 in binary
int b = 3;  // 0011 in binary
int c = a | b;  // 0111 in binary, which is 7 in decimal
```

##### Bitwise XOR Operator

The bitwise XOR operator `^` performs a logical exclusive OR operation on each pair of corresponding bits of its operands. The result is `1` if the bits are different, and `0` if they are the same.

General form of the bitwise XOR operator is:

```c
expression1 ^ expression2
```

Example:
```c
int a = 5;  // 0101 in binary
int b = 3;  // 0011 in binary
int c = a ^ b;  // 0110 in binary, which is 6 in decimal
```

##### Bitwise NOT Operator

The bitwise NOT operator `~` performs a logical NOT operation on each bit of its operand. The result is `1` if the bit is `0`, and `0` if the bit is `1`.

General form of the bitwise NOT operator is:

```c
~expression
```

Example:
```c
int a = 5;  // 0000000000000101 in binary
int b = ~a;  // 1111111111111010 in binary, which is 65530 in decimal
```

Here is a table with an example (the first three columns are the **Expressions** and the last three columns are the **Results**):

| **Decimal** | **Hex** | **Binary** | **Decimal** | **Hex** | **Binary** |
|--------------|---------|------------|-------------|---------|------------|
| 12 & 10 | 0x0C & 0x0A | 1100 & 1010 | 8 | 0x08 | 1000 |
| 12 \| 10 | 0x0C \| 0x0A | 1100 \| 1010 | 14 | 0x0E | 1110 |
| 12 ^ 10 | 0x0C ^ 0x0A | 1100 ^ 1010 | 6 | 0x06 | 0110 |
| ~12 | ~0x000C | ~0000000000001100 | 65523 | 0xFFF3 | 1111111111110011 |

The complementary of 12 is 65523 because the bitwise NOT operator flips all the bits of the number. In a 16-bit representation, 12 is represented as `0000000000001100`. When we apply the bitwise NOT operator, we get `1111111111110011`, which is equal to 65523 in decimal.

##### Left Shift Operator

The left shift operator `<<` shifts the bits of its left-hand operand to the left by the number of positions specified by its right-hand operand. The vacant positions on the right are filled with zeros.

General form of the left shift operator is:

```c
expression << number_of_positions
```

Example:
```c
int a = 5;  // 0101 in binary
int b = a << 1;  // 1010 in binary, which is 10 in decimal
int c = a << 2;  // 10100 in binary, which is 20 in decimal
```

:::info[Multiply by power of 2]
Using the left shift operator `<<` is equivalent to multiplying by a power of 2. For example, `a << 1` is equivalent to `a * 2` (${a}\cdot{2^1}$), and `a << 2` is equivalent to `a * 4` (${a}\cdot{2^2}$), and `a << 3` is equivalent to `a * 8` (${a}\cdot{2^3}$).
:::

##### Right Shift Operator

The right shift operator `>>` shifts the bits of its left-hand operand to the right by the number of positions specified by its right-hand operand. The vacant positions on the left are filled with zeros for unsigned types and with the sign bit for signed types.

General form of the right shift operator is:

```c
expression >> number_of_positions
```

Example:
```c
int a = 20;  // 10100 in binary
int b = a >> 1;  // 01010 in binary, which is 10 in decimal
int c = a >> 2;  // 00101 in binary, which is 5 in decimal
```

:::info[Divide by power of 2]
Using the right shift operator `>>` is equivalent to dividing by a power of 2. For example, `a >> 1` ($\cfrac{a}{2^1}$) is equivalent to `a / 2` ($\cfrac{a}{2^2}$), and `a >> 2` is equivalent to `a / 4`, and `a >> 3` is equivalent to `a / 8` ($\cfrac{a}{2^3}$).
:::

### Conditional Operator

The conditional operator `?:` evaluates a condition and returns one of two values based on whether the condition is true or false.

General form of the conditional operator is:

```c
condition ? value_if_true : value_if_false
```

Example:
```c
int a = 10;
int b = (a > 5) ? 1 : 0;  // b is 1 because a > 5 is true
int c = (a < 5) ? 1 : 0;  // c is 0 because a < 5 is false
```
