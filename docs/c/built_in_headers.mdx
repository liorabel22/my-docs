## `stdio.h`

The `stdio.h` [header file](/docs/c/keywords.mdx#header-file) is part of the C standard library and provides [input and output operations](/docs/c/keywords.mdx#input-and-output-operation). It includes functions for reading from and writing to [standard input](/docs/c/keywords.mdx#standard-input) and [standard output](/docs/c/keywords.mdx#standard-output), as well as [file handling](/docs/c/keywords.mdx#file-handling).

Functions declared in `stdio.h` include:
- [`fclose`](/docs/c/built_in_functions.mdx#fclose): Closes an opened [file](/docs/c/keywords.mdx#file).
- [`feof`](/docs/c/built_in_functions.mdx#feof): Checks if the [end of a file](/docs/c/keywords.mdx#end-of-file-eof) has been reached.
- [`ferror`](/docs/c/built_in_functions.mdx#ferror): Checks for errors in [file handling](/docs/c/keywords.mdx#file-handling).
- [`fgetc`](/docs/c/built_in_functions.mdx#fgetc): Reads a [character](/docs/c/keywords.mdx#character) from a [file](/docs/c/keywords.mdx#file).
- [`fgets`](/docs/c/built_in_functions.mdx#fgets): Reads a [string](/docs/c/keywords.mdx#string) from a [file](/docs/c/keywords.mdx#file).
- [`fopen`](/docs/c/built_in_functions.mdx#fopen): Opens a [file](/docs/c/keywords.mdx#file) and returns a [file pointer](/docs/c/keywords.mdx#file-pointer).
- [`fprintf`](/docs/c/built_in_functions.mdx#fprintf): Writes formatted output to a [file](/docs/c/keywords.mdx#file).
- [`fputc`](/docs/c/built_in_functions.mdx#fputc): Writes a [character](/docs/c/keywords.mdx#character) to a [file](/docs/c/keywords.mdx#file).
- [`fputs`](/docs/c/built_in_functions.mdx#fputs): Writes a [string](/docs/c/keywords.mdx#string) to a [file](/docs/c/keywords.mdx#file).
- [`fread`](/docs/c/built_in_functions.mdx#fread): Reads data from a [file](/docs/c/keywords.mdx#file) into [memory](/docs/c/keywords.mdx#memory).
- [`fscanf`](/docs/c/built_in_functions.mdx#fscanf): Reads formatted input from a [file](/docs/c/keywords.mdx#file).
- [`fseek`](/docs/c/built_in_functions.mdx#fseek): Moves the [file pointer](/docs/c/keywords.mdx#file-pointer) to a specific location in a [file](/docs/c/keywords.mdx#file).
- [`ftell`](/docs/c/built_in_functions.mdx#ftell): Returns the current position of the [file pointer](/docs/c/keywords.mdx#file-pointer).
- [`fwrite`](/docs/c/built_in_functions.mdx#fwrite): Writes data from [memory](/docs/c/keywords.mdx#memory) to a [file](/docs/c/keywords.mdx#file).
- [`getc`](/docs/c/built_in_functions.mdx#getc): Reads a [character](/docs/c/keywords.mdx#character) from [standard input](/docs/c/keywords.mdx#standard-input).
- [`getchar`](/docs/c/built_in_functions.mdx#getchar): Reads a [character](/docs/c/keywords.mdx#character) from [standard input](/docs/c/keywords.mdx#standard-input).
- [`printf`](/docs/c/built_in_functions.mdx#printf): Outputs formatted text to [standard output](/docs/c/keywords.mdx#standard-output) using [format specifiers](/docs/c/keywords.mdx#format-specifier).
- [`putc`](/docs/c/built_in_functions.mdx#putc): Writes a [character](/docs/c/keywords.mdx#character) to [standard output](/docs/c/keywords.mdx#standard-output).
- [`putchar`](/docs/c/built_in_functions.mdx#putchar): Writes a [character](/docs/c/keywords.mdx#character) to [standard output](/docs/c/keywords.mdx#standard-output).
- [`puts`](/docs/c/built_in_functions.mdx#puts): Writes a [string](/docs/c/keywords.mdx#string) to [standard output](/docs/c/keywords.mdx#standard-output).
- [`remove`](/docs/c/built_in_functions.mdx#remove): Deletes a [file](/docs/c/keywords.mdx#file).
- [`rename`](/docs/c/built_in_functions.mdx#rename): Renames a [file](/docs/c/keywords.mdx#file).
- [`rewind`](/docs/c/built_in_functions.mdx#rewind): Resets the [file position indicator](/docs/c/keywords.mdx#file-position-indicator) to the beginning of a [file](/docs/c/keywords.mdx#file).
- [`scanf`](/docs/c/built_in_functions.mdx#scanf): Reads formatted input from [standard input](/docs/c/keywords.mdx#standard-input) using [format specifiers](/docs/c/keywords.mdx#format-specifier).
- [`snprintf`](/docs/c/built_in_functions.mdx#snprintf): Writes formatted output to a [string](/docs/c/keywords.mdx#string).
- [`sprintf`](/docs/c/built_in_functions.mdx#sprintf): Writes formatted output to a [string](/docs/c/keywords.mdx#string).
- [`sscanf`](/docs/c/built_in_functions.mdx#sscanf): Reads formatted input from a [string](/docs/c/keywords.mdx#string).
