## `stdio.h`

The `stdio.h` header file is part of the C standard library and provides functionalities for input and output operations. It includes functions for reading from and writing to standard input and output, as well as file handling.

Functions declared in `stdio.h` include:
- [`fclose`](/docs/c/built_in_functions.mdx#fclose): Closes an opened file.
- [`feof`](/docs/c/built_in_functions.mdx#feof): Checks if the end of a file has been reached.
- [`ferror`](/docs/c/built_in_functions.mdx#ferror): Checks for errors in file operations.
- [`fgetc`](/docs/c/built_in_functions.mdx#fgetc): Reads a character from a file.
- [`fgets`](/docs/c/built_in_functions.mdx#fgets): Reads a string from a file.
- [`fopen`](/docs/c/built_in_functions.mdx#fopen): Opens a file and returns a file pointer.
- [`fprintf`](/docs/c/built_in_functions.mdx#fprintf): Writes formatted output to a file.
- [`fputc`](/docs/c/built_in_functions.mdx#fputc): Writes a character to a file.
- [`fputs`](/docs/c/built_in_functions.mdx#fputs): Writes a string to a file.
- [`fread`](/docs/c/built_in_functions.mdx#fread): Reads data from a file into memory.
- [`fscanf`](/docs/c/built_in_functions.mdx#fscanf): Reads formatted input from a file.
- [`fseek`](/docs/c/built_in_functions.mdx#fseek): Moves the file pointer to a specific location in a file.
- [`ftell`](/docs/c/built_in_functions.mdx#ftell): Returns the current position of the file pointer.
- [`fwrite`](/docs/c/built_in_functions.mdx#fwrite): Writes data from memory to a file.
- [`getc`](/docs/c/built_in_functions.mdx#getc): Reads a character from standard input.
- [`getchar`](/docs/c/built_in_functions.mdx#getchar): Reads a character from standard input.
- [`printf`](/docs/c/built_in_functions.mdx#printf): Outputs formatted text to the standard output.
- [`putc`](/docs/c/built_in_functions.mdx#putc): Writes a character to standard output.
- [`putchar`](/docs/c/built_in_functions.mdx#putchar): Writes a character to standard output.
- [`puts`](/docs/c/built_in_functions.mdx#puts): Writes a string to standard output.
- [`remove`](/docs/c/built_in_functions.mdx#remove): Deletes a file.
- [`rename`](/docs/c/built_in_functions.mdx#rename): Renames a file.
- [`rewind`](/docs/c/built_in_functions.mdx#rewind): Resets the file pointer to the beginning of a file.
- [`scanf`](/docs/c/built_in_functions.mdx#scanf): Reads formatted input from the standard input.
- [`snprintf`](/docs/c/built_in_functions.mdx#snprintf): Writes formatted output to a string.
- [`sprintf`](/docs/c/built_in_functions.mdx#sprintf): Writes formatted output to a string.
- [`sscanf`](/docs/c/built_in_functions.mdx#sscanf): Reads formatted input from a string.
